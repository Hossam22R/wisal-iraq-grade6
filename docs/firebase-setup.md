# دليل تشغيل منصة مدارس براعم كربلاء الأهلية

هذه الخطوات تُنفَّذ مرة واحدة بحساب Google الخاص بالمدرسة، وتستغرق نحو ربع ساعة.
بعدها تعمل الحسابات والرسائل الخاصة وحفظ نتائج الامتحانات والواجبات.

## ١. إنشاء مشروع Firebase
1. افتح https://console.firebase.google.com وسجّل الدخول بحساب Google الخاص بالمدرسة.
2. اضغط **Create a project** واكتب اسماً مثل `baraem-karbala`.
3. يمكنك إيقاف Google Analytics، ثم اضغط **Create project**.

## ٢. تسجيل الموقع وأخذ الإعدادات
1. في صفحة المشروع اضغط أيقونة الويب `</>`.
2. اكتب اسماً للتطبيق مثل `portal` واضغط **Register app**.
3. ستظهر لك كتلة `firebaseConfig`. انسخ ما بين القوسين `{ ... }`.
4. افتح في GitHub الملف `assets/firebase-config.js`، واضغط أيقونة القلم للتعديل، واستبدل `null` بما نسخته، بهذا الشكل:

```js
window.FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." };
```

5. اضغط **Commit changes**.

هذه الإعدادات ليست كلمة سر، ونشرها في الموقع طبيعي. الحماية تأتي من القواعد في الخطوة ٤.

## ٣. تفعيل طرق الدخول
1. من القائمة الجانبية: **Build ← Authentication ← Get started**.
2. في تبويب **Sign-in method** فعّل:
   - **Email/Password**: المفتاح الأول فقط، لحسابات المالك والمشرفين.
   - **Anonymous**: للتلاميذ وأولياء الأمور، ليدخلوا دون حسابات.
3. في تبويب **Settings ← Authorized domains** أضف نطاق الموقع، مثل `hossam22r.github.io`.

## ٤. إنشاء قاعدة البيانات ونسخ قواعد الحماية
1. **Build ← Firestore Database ← Create database**.
2. اختر موقعاً قريباً، مثل أحد مواقع أوروبا، ثم **Production mode**.
3. افتح تبويب **Rules**، واحذف ما فيه، والصق محتوى الملف `firestore.rules` من المستودع كاملاً، ثم اضغط **Publish**.

## ٥. تفعيل الموقع على GitHub Pages
1. في المستودع: **Settings ← Pages**.
2. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقائق يظهر رابط الموقع، مثل `https://hossam22r.github.io/wisal-iraq-grade6/`.

## ٦. إنشاء حساب المالك (فوراً)
1. افتح `admin.html` في رابط الموقع.
2. ستظهر صفحة **إنشاء حساب المالك**. اكتب اسمك واسم مستخدم وكلمة سر قوية.
3. أول من ينشئ هذا الحساب يصبح المالك، ولا يمكن تغييره بعدها، لذلك أنشئه قبل نشر الرابط لأي أحد.

## ٧. بعد التشغيل
- **إضافة المشرفين:** من «الحسابات والصلاحيات». أعطِ كل مشرف اسم المستخدم وكلمة السر، ويغيّرها هو من «حسابي».
- **من يستقبل الرسائل:** فعّل «يستقبل رسائل أولياء الأمور» لكل من تريد أن يظهر في قائمة التواصل.
- **نقل المحتوى القديم:** من «المدرسة والمراحل ← نقل المحتوى» يُنقل محتوى الملف الثابت مرة واحدة.
- **الاختبارات:** من «الاختبارات والنتائج ← اختبار أو واجب جديد». بعد النشر يظهر في البوابة لتلاميذ الصف، وتصل إجاباتهم إلى صفحة النتائج.

## الصلاحيات
| الصلاحية | المالك | مشرف النشر |
|---|---|---|
| نشر التبليغات والواجبات والامتحانات والدروس والمناسبات والنشاطات | ✔ | ✔ |
| تعديل وحذف منشورات الآخرين | ✔ | ✘ |
| إنشاء الاختبارات الإلكترونية ورؤية نتائجها | كل الاختبارات | اختباراته فقط |
| قراءة الرسائل الخاصة | كل رسائل المدرسة | الموجهة إليه فقط |
| الحسابات وبيانات المدرسة والمراحل | ✔ | ✘ |

## طريقتا التصحيح
- **فورية:** يرى التلميذ درجته والتصحيح مباشرة. الإجابات تصل إلى جهازه، فتناسب الواجبات والتدريب.
- **محمية:** الإجابات لا تصل إلى جهاز التلميذ أبداً. يرى المعلم الدرجات، ثم يضغط «اعتماد النتائج» فتظهر للتلاميذ. تناسب الامتحانات.

## ملاحظات
- **الخطة المجانية (Spark)** لها حدود يومية للقراءة والكتابة. تتابع الاستهلاك من صفحة **Usage** في Firebase.
- **الصور:** لا تُرفع صور على المنصة حالياً، بل يُضاف رابط الصورة.
- **إذا نسي مشرف كلمة السر:** عطّل حسابه وأنشئ له حساباً جديداً.
